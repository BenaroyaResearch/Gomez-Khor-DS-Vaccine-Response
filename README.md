# Gomez Khor DS Vaccine Response

Analysis code for the COVID vaccine response study in Down syndrome and typical controls.

## Analysis collections

1. [IMPACD workflows](IMPACD/README.md): CyTOF and flow cytometry gating, Level 1 statistics, and modifier analysis.
2. [Single cell analysis code](scRNAseqAnalysisCode/README.md): Documentation for the existing single cell analysis collection.

See each collection's README for its files, inputs, and execution requirements.
